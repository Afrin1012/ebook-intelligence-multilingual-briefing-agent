# E-Book Intelligence & Multilingual Briefing Agent

Python + Streamlit app for e-book analysis and multilingual briefings.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Project layout

- `app.py` — Streamlit UI entry point
- `src/` — processing, retrieval, and briefing modules (to be implemented)
